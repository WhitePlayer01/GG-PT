# GG-PT · 云长卫

一个原生 macOS 桌面收纳助理。把 Finder 中的文件或文件夹拖到关羽桌宠身上，它会播放挥刀动画，并按文件类型移动到指定目录。

## 使用流程

1. 首次启动时选择一个总收纳目录。
2. 将引导示例或 Finder 中的真实文件拖到桌宠身上。
3. 应用先按自定义军令匹配，未命中时再使用内置八分类。
4. 文件移动完成后写入本机历史，可以从桌宠右键菜单一键撤回。
5. 如需自动整理，可在设置中单独开启桌面或下载目录巡查。

设置页面采用任务分栏结构：左侧在常规、自动化、高级军令、战报和版本更新之间切换，右侧只呈现当前任务所需配置，减少长页面滚动和无关信息干扰。

“常规 → 桌宠外观”提供 35%–100% 桌宠透明度调节；拖动时桌面关羽窗口实时变化，设置窗口保持清晰，默认值为 100%。

## 桌宠与手动收纳

- 透明、置顶、跨桌面的桌宠窗口
- Finder 文件/文件夹拖放
- 图片、文档、视频、音频、压缩包、代码、文件夹、其他八类目录
- 自定义总目录和每一类子目录
- 同名文件自动编号，避免覆盖
- 右键桌宠可打开设置、收纳箱或退出
- 55%–145% 宠物尺寸调节，窗口会随宠物一起缩放
- 可在设置中显示或隐藏桌宠右上角的设置图标
- 四态角色反馈：待机呼吸、拖入接收、失败摇头、完成庆功；均使用透明角色立绘并自动回到待机
- 每种状态会轮换多套轻量动作，安静模式下自动降低幅度
- 图片、文档、视频、音频、压缩包、代码、文件夹等分类会触发不同关公台词
- 三款角色皮肤、三种兵器光效和四种主题策略可随时切换
- 支持屏幕边缘吸附、跨显示器拖动、显示器拔插后的自动归位和位置记忆
- 使用系统音效提供独立声音开关；安静模式同时关闭声音与常驻动作
- 自动识别传统节日、公历节日和二十四节气，显示限定台词与动画
- 桌宠可显示今日收纳数量与连续整理天数
- 首次启动两步引导：选择收纳箱，并真实拖放示例文件

设置图标隐藏后，仍可右键桌宠选择“收纳设置…”，因此不会失去设置入口。

## 自定义军令

- 按文件名关键词、扩展名、来源路径、文件大小和创建时间组合匹配
- 来源位置可直接选择电脑文件夹，也可一键选择桌面、下载或文稿目录
- 文件大小提供 0–100 MB 推荐值、小文件、大文件和不限大小预设
- 创建时间提供最近 30 天推荐值、最近 7 天、30/90 天前和不限时间预设
- 推荐值之外仍可展开“精确设置”输入自定义上下限
- 新军令默认关闭，并预填“最近 30 天、100 MB 以下、收纳到待整理”的安全模板
- 一条军令中已填写的条件必须同时满足
- 多条军令从上到下匹配，首条命中后停止
- 军令可以启用、停用、上移、下移和删除
- “预览文件命中”只展示规则、智能文件名和目标路径，不移动文件
- 未命中任何军令的文件继续使用内置八分类

## 自动巡查与安全边界

- 桌面和下载目录可分别启用
- 支持 5、15、30、60 分钟巡查间隔
- 支持设置页按钮和桌宠右键菜单立即巡查
- 默认关闭自动巡查，升级后不会自行移动文件
- 只扫描目录第一层的普通文件，不移动文件夹
- 跳过隐藏文件、未完成下载和最近一分钟仍在修改的文件
- 自动排除总收纳目录及包含总收纳目录的候选路径
- 30 天前的安装包和压缩包只生成清理提醒，不自动移动或删除

## 归档、查重与命名

- SHA-256 内容重复检测，先比较文件大小再计算哈希
- 重复文件保留在原处，不覆盖或删除源文件
- 可按文件自身修改/创建日期生成 `分类/年/月` 目录
- 智能命名支持保留原名、日期 + 原名、来源 + 日期 + 原名、类型 + 日期 + 原名
- 同名目标自动追加 `-2`、`-3` 等编号
- 清理提醒包括空文件夹、30 天前安装包和 30 天前压缩包

## 历史、撤回与今日战报

- 最近 100 次拖放、网页投递和自动巡查保存在本机
- 一次拖入的多个文件作为同一批次撤回
- 撤回时如果原位置已有同名文件，该文件保持不动，绝不覆盖
- 网页下载文件撤回时删除下载副本，本地拖放文件恢复到原位置
- 今日战报统计行动次数、收纳数量、重复数量、避免重复占用空间、失败数量和分类分布
- 今日战报同时展示当前连续整理天数，桌宠右键菜单也可快速查看

## 网页投递

- Chrome / Edge 扩展提供工具栏收纳面板和右键菜单
- 支持当前图片、正文 Markdown、系统打印 PDF、链接待收纳和全页图片批量收集
- 收纳时可指定目标分类和标签；文件保留来源 URL、采集时间与标签元数据
- 网页和普通链接保存为 macOS `.webloc` 书签
- 图片、音频和视频由桌面 App 下载后进入相同军令和分类流程
- 浏览器通过 `erye://collect` 深链唤起桌面 App
- 只接受 `http` 和 `https` 地址，拒绝本地文件及脚本协议

## 版本更新

- 启动时自动检查 GitHub Releases，新版本会显示更新说明和下载入口
- 可在设置中手动检查更新或关闭启动检查
- 优先下载 Release 中的 `.dmg`、`.pkg` 或 `.zip`，没有附件时打开发布页

## 隐私与本机数据

- Finder 拖放、分类、查重和历史记录均在本机完成
- 操作历史保存在用户 Application Support 目录
- 用户设置和军令保存在 UserDefaults
- 网页小工具使用浏览器本地存储，不上传所选素材
- 只有检查更新和网页媒体投递会访问网络

## 本地运行

```bash
swift run PetSorter
```

## 构建应用

```bash
./scripts/build-app.sh
```

构建完成后，双击 `dist/云长卫.app` 即可运行。

> 构建脚本会把角色图片放入标准的 `Contents/Resources` 目录，
> 应用通过主 Bundle 直接读取，确保独立运行时也能正确显示。

## 一键生成 DMG 安装包

打包前请确认当前 Mac 已安装 Swift 6 工具链或 Xcode Command Line Tools。直接双击项目根目录的 `一键打包.command`，脚本会自动完成以下流程：

1. 使用 release 配置编译应用。
2. 装配并临时签名 `云长卫.app`。
3. 使用应用的 `AppIcon.icns` 作为 DMG 文件及安装盘图标。
4. 创建包含应用和“Applications”快捷方式的压缩 DMG。
5. 成功后自动打开 `dist` 文件夹。

需要在终端或持续集成环境中打包时，运行：

```bash
./scripts/build-dmg.sh
```

应用版本读取自 `AppInfo.plist` 的 `CFBundleShortVersionString`，生成文件名同时包含版本和当前 Mac 架构，例如 `dist/云长卫-0.4.0-arm64.dmg`。相同版本与架构的旧产物会被新产物替换。

打开生成的安装包后，将“云长卫”拖入“Applications”即可安装。`dist` 是本机构建目录，已被 Git 忽略，不会把 DMG 二进制文件提交到仓库。

> 当前产物使用本机临时签名，适合本机测试或内部传发。若要公开分发并消除 Gatekeeper 警告，还需要配置 Apple Developer ID 签名与公证。

## 项目结构

- 详细的模块划分、数据流和发布边界见 [项目结构说明](项目结构说明.md)
- `Sources/PetSorter`：macOS SwiftUI 桌面应用
- `Sources/PetSorter/Resources`：桌宠立绘、图标和挥刀逐帧动画
- `browser-extension`：Chrome、Edge 等 Chromium 浏览器扩展
- `minitool-dist`：可离线使用的移动端网页小工具
- `scripts/build-app.sh`：release 构建、资源装配和本机签名脚本
- `scripts/build-dmg.sh`：构建 App 并生成压缩 DMG 安装包
- `一键打包.command`：可双击执行的一键打包入口
- `AppInfo.plist`：应用标识、版本、深链和辅助应用配置

## 安装浏览器扩展

1. 先运行一次构建好的 `云长卫.app`。
2. 在 Chrome 或 Edge 的扩展管理页开启开发者模式。
3. 选择“加载已解压的扩展程序”，选中 `browser-extension` 目录。
4. 在网页、链接、图片或音视频上点右键，选择“交给二爷”。

网页与普通链接会保存为可双击回访的 `.webloc` 文件；图片、音频和视频会下载后按桌面 App 的现有分类规则归档。

## 当前平台要求

- macOS 13 或更高版本
- Swift 6 工具链
- 浏览器投递扩展需要 Chrome、Edge 或其他支持 Manifest V3 的 Chromium 浏览器
