# 二爷收着

一个原生 macOS 桌面宠物。把 Finder 中的文件或文件夹拖到关羽桌宠身上，它会播放挥刀动画，并按文件类型移动到指定目录。

## 功能

- 透明、置顶、跨桌面的桌宠窗口
- Finder 文件/文件夹拖放
- 图片、文档、视频、音频、压缩包、代码、文件夹、其他八类目录
- 自定义总目录和每一类子目录
- 同名文件自动编号，避免覆盖
- 最近收纳历史与一键撤回
- 右键桌宠可打开设置、收纳箱或退出
- 55%–145% 宠物尺寸调节，窗口会随宠物一起缩放
- 拖放后播放由参考视频转换得到的 4.1 秒透明挥刀动画
- Chrome / Edge 扩展右键投递网页、链接、图片与音视频
- 网页素材通过 `erye://` 唤起 App 后自动下载和分类

## 本地运行

```bash
swift run PetSorter
```

## 构建应用

```bash
./scripts/build-app.sh
```

构建完成后，双击 `dist/二爷收着.app` 即可运行。

> 构建脚本会把角色图片放入标准的 `Contents/Resources` 目录，
> 应用通过主 Bundle 直接读取，确保独立运行时也能正确显示。

## 安装浏览器扩展

1. 先运行一次构建好的 `二爷收着.app`。
2. 在 Chrome 或 Edge 的扩展管理页开启开发者模式。
3. 选择“加载已解压的扩展程序”，选中 `browser-extension` 目录。
4. 在网页、链接、图片或音视频上点右键，选择“交给二爷”。

网页与普通链接会保存为可双击回访的 `.webloc` 文件；图片、音频和视频会下载后按桌面 App 的现有分类规则归档。
