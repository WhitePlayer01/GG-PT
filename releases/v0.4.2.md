# 云长卫 0.4.2

本次更新带来听歌陪伴、全新设置界面，以及桌宠资源占用优化；同时汇总上次公开版本以来的网页收纳与归档改进。

## 新增与改进

- **听歌记录**：接入 Apple Music、Spotify 桌面播放器及浏览器音乐页面；支持本机保存、查看、JSON 导出和主动清空，默认关闭。
- **网易云桌面状态识别**：经辅助功能授权后读取明确的播放／暂停菜单状态，驱动桌宠听歌形态。当前不读取桌面版歌名，也不生成该来源的歌曲历史。
- **五款听歌动作**：闭眼轻晃、扶耳点头、握拳打拍、张臂摇摆、盘坐沉浸，随机轮播并避免连续重复；支持安静模式和系统减少动态效果。
- **设置界面改版**：统一侧栏、分组和青绿强调色，加入角色实时预览，并适配系统深浅色。
- **资源占用优化**：角色图片按显示尺寸解码、按需缓存；减少重复播放状态通知、动画布局和模糊合成。低电量模式将听歌动画降至 12fps，正常模式保留 24fps。
- **网页收纳与记录**：扩展与 App 本机直连，完善投递反馈和文件去向记录。
- **归档改进**：按月整理使用单层 `分类/YYYY-MM` 目录；提供带应用图标的拖拽安装 DMG。

图片缓存测试中，六张角色图的解码像素内存由约 36 MiB 降至 10.8 MiB，减少约 70%。此数据不代表整个进程的内存或 CPU 降幅，实际占用取决于播放场景、缩放与系统环境。

## 下载与安装

- 安装包：`云长卫-0.4.2-arm64.dmg`
- 平台：Apple Silicon（M 系列芯片），macOS 13 或更高版本；本次不提供 Intel 安装包。
- 构建号：6。
- 先退出旧版，打开 DMG，将“云长卫”拖入“Applications”，再启动应用。
- 浏览器听歌需更新仓库中的 `browser-extension`（0.8.0），在 App 和扩展两端开启听歌记录，再刷新音乐网页。扩展不包含在 DMG 中，可从此版本源代码包获取。

## 权限与已知限制

- 安装包采用本机临时签名，**尚未使用 Developer ID 签名或通过 Apple 公证**；其他 Mac 上可能出现 Gatekeeper 提示。仅在确认下载来源可信后，按系统提供的审核流程处理。
- 不录音、不录屏，不上传听歌记录；播放器接入可能需要系统自动化或辅助功能授权。
- 音乐网页须提供 Media Session 信息，允许列表不等于所有站点版本都已实机验证。QQ 音乐桌面版暂未接入。
- 收听时长为约 5 秒采样的估算值；未知播放状态不累计时长。网易云完整授权后的真实播放、后台及最小化场景仍需进一步实机验证。

## 验证

通过 release 编译、图片缓存测试，以及听歌记录、网页消息、网易云菜单解析、随机动作轮播的现有回归测试。
